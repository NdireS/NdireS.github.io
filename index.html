Built to Last uploader

Built to Last uploader is a small private tool used by the YouTube channel Built to Last (@BuiltToLastTV), a channel about relationships, marriage and family.

It runs on the channel owner's own computer. Once a day it uploads the channel's finished Shorts to that same channel through the YouTube Data API, with each video's title, description, hashtags and thumbnail, and posts the channel's first comment on each new Short.

It is not offered to the public, and it only works with the channel owner's own account.
