Privacy policy

Last updated: 22 November 2026

This policy covers Built to Last uploader, a private tool that uploads videos to the YouTube channel Built to Last (@BuiltToLastTV). It is used only by that channel's owner, with the owner's own Google account.

What the tool accesses

With the owner's permission, given through Google's sign-in screen, the tool uses the YouTube Data API to:

  • upload videos to the owner's own channel, with their titles, descriptions and tags;
  • set those videos' thumbnails;
  • post a comment on those videos from the owner's channel;
  • read the channel's ID and name, and the processing status of the videos it uploaded.

It does not read anyone else's data, and it does not collect data from viewers.

How the data is stored

The sign-in token Google issues is stored only on the channel owner's own computer. The tool has no server and no database, and it keeps no copy of the owner's Google data elsewhere.

Sharing

No data is sold, shared with, or transferred to anyone. It is not used for advertising, and it is not used for any purpose other than publishing the channel's own videos.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be withdrawn at any time from the Google account's third-party connections page. Deleting the token file on the owner's computer also stops the tool.

Contact

Questions about this policy can be sent through the Built to Last YouTube channel.
